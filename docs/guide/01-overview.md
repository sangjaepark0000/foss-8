### 1.2 프로젝트 목적

- GitHub 기반 실무형 협업 능력 습득

- 오픈소스 문화 이해 및 기여 체험 — 문서·라이선스·행동 수칙을 갖춘 저장소 운영, 타 팀 저장소에 기여

- 코딩 실력 향상 및 기능 설계 역량 강화

- 팀워크와 커뮤니케이션 능력 향상

- 실질적인 GitHub 활동 기록(Contribution, 리뷰, PR 등) 축적 — 학기가 끝나면 내 프로필에 커밋·풀 리퀘스트·리뷰 기록이 남음

<a id="section-1-3"></a>

### 1.3 프로젝트 완성 기준 5개

최종발표 때 아래 5개를 만족해야 하며, 이 5개가 결과물 점수(30점)의 기준입니다.

| # | 완성 기준 | 확인 방법 |
| --- | --- | --- |
| 1 | GitHub 공개 저장소에 v1.0.0 태그가 있고, README의 설치·실행 방법대로 새 PC에서<br>실행됨 | 저장소 태그, 다른 팀원의 재현 |
| 2 | 핵심 기능 4개(팀원 1인 1기능)가 동작하고 발표에서 시연 | 시연, README 기능 표 |
| 3 | README, LICENSE, CONTRIBUTING, 행동 수칙(CODE\_OF\_CONDUCT) 파일이<br>있음 | 저장소 첫 화면 |
| 4 | 모든 기능이 브랜치 → 풀 리퀘스트 → 리뷰 → 병합으로 main에 들어감 | Pull requests 목록 |
