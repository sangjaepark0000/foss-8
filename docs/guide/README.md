## 읽는 방법

각 문서는 원문의 내용을 보존하며, 소제목·표·코드 블록과 장 사이 링크로 탐색할 수 있습니다. 문서 위·아래의 이전/다음 링크로 원문 순서대로 읽을 수도 있습니다.

원문은 일반적인 **4인 팀·핵심 기능 4개**를 기준으로 쓰였습니다. foss-8의 승인된 3인 팀 구성, 회의록 제출자, 작업 순서는 [팀 적용 사항](team-context.md)에 기록했습니다. 원문을 읽을 때 함께 확인합니다.

PDF 인쇄 줄바꿈과 표의 셀 내부 줄바꿈은 유지한 곳이 있습니다. PDF에서 여러 행에 걸친 병합 셀은 첫 행에 값을 쓰고 이어지는 행을 비워 같은 묶음을 나타냅니다. 양식의 예시 이름·날짜·프로젝트 이름은 원문 예시입니다.
