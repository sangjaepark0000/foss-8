## [부록 F](appendix-f-team-template.md). 팀 약속 양식

docs/team-agreement.md로 저장하고 2주차 회의에서 4명이 확인합니다.

```markdown
# 팀 약속 — 팀명

작성일: 2026-09-11 / 확인: 홍길동, 김철수, 이영희, 박민수

## 1. 팀원과 역할
| 이름 | 역할 | GitHub | 담당 기능 |
|---|---|---|---|
| 홍길동 | 팀장 | @hong-id | add |
| 김철수 | 개발 리드 | @kim-id | summary + 공통 코드 |
| 이영희 | 문서 담당 | @lee-id | budget |
| 박민수 | 리뷰·품질 담당 | @park-id | chart |

## 2. 소통
- 채널: 디스코드 서버 '팀명'
- 정기 회의: 매주 화요일 20:00~21:00, 온라인. 불참 시 전날까지 알림
- 응답: 채팅 24시간, 풀 리퀘스트 리뷰 48시간

## 3. 작업 규칙
- 작업 전 이슈 등록, 하루 작업 끝에 Push
- 브랜치·커밋·풀 리퀘스트 규칙은 안내서 8장
- main.py·공통 파일을 고칠 때는 이슈 댓글로 먼저 알림

## 4. 의사결정
- 회의에서 다수결, 동률이면 개발 리드 결정. 결정과 이유는 회의록에 기록

## 5. 문제 대응
- 1주 무응답 → 팀장 연락 / 2주 → 회의록 기록 + 교수 상담
```
