## 안내서 사용법

이 안내서는 Git과 GitHub를 처음 접하는 학생을 기준으로 썼습니다. 사용하는 도구와 방법은 모두 수업 강의자료와 같습니다. 수업에서 배운 것을 그 주에 팀 저장소에 적용하면 프로젝트가 진행되도록 짜여 있으니, 매주 '이번 주 할 일 '만 따라오면 됩니다.

구성

| 부 | 장 | 내용 | 읽는 시기 |
| --- | --- | --- | --- |
| 1부 개요 | 1~3장 | 목적, 완성 기준, 팀 구성, 15주 로드맵 | 지금 바로 |
| 2부 계획 | 4~5장 | 주제 정하기, 제안서 | 2~5주차 |
| 3부 준비 | 6~7장 | 계정·도구 준비, 팀 저장소 만들기 | 3~6주차 |
| 4부 협업 | 8~10장 | 매주 반복하는 협업 루틴, Python 프로젝트 기본, 활동 규칙(평가 30점) | 6주차부터 매주 |
| 5부 확장·마무리 | 11~16장 | 타 팀 기여, 회의록, 중간발표, 릴리스·최종보고서·발표, 평가, 도움 받기 | 10주차부터 |
| 부록 | A~F | 점검표, 회의록 양식, 템플릿 파일, 소스트리·명령어 대응표와 충돌 실습,<br>FAQ, 팀 약속 | 필요할 때 |

표기 규칙

- 이렇게 표시된 글자는 화면의 버튼·메뉴 이름, 파일 이름, 또는 Git Bash에 입력하는 명령

- \[필수\]는 평가에 반영되는 항목, \[주의\]는 자주 하는 실수, \[TIP\]은 요령, \[수업\]은 같은 내용을 배우는 수업 주차

- '각자'는 4명 모두에게 적용되는 기준, '팀'은 팀 단위로 1회면 되는 기준

- '주차'는 수업 회차입니다(예: 5주차 = 10/2 수업). 모든 제출물의 제출 마감은 수업일 전날(목요일) 18:00

- 소스트리(GUI)와 Git Bash(명령어) 중 편한 쪽을 쓰면 됩니다. 본문은 수업 6~13 주차에 쓰는 소스트리를 기준으로 쓰고, 명령어는 [부록 D](appendix-d-git-drill.md)에 정리했습니다
