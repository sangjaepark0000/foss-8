## 15. 평가

프로젝트 점수 100점은 과목 성적의 50%로 환산됩니다 (출결 10%, 중간고사 40%, 팀 프로젝트 50%).

| 구분 | 내용 | 세부 | 점수 |
| --- | --- | --- | --- |
| 보고서 및 발표 (40) | 프로젝트 제안서 | 제안서 ([15.1절](15-evaluation.md#section-15-1)) | 10 |
|  |  | 발표 | 5 |
|  | 중간보고서 | 중간보고서 ([15.2절](15-evaluation.md#section-15-2)) | 5 |
|  |  | 중간발표 | 5 |
|  | 최종보고서 | 최종보고서 ([15.3절](15-evaluation.md#section-15-3)) | 10 |
|  |  | 최종발표 | 5 |
| 프로젝트 활동 (60) | 활동 규칙 준수 여부 | 10개 항목 × 3점 (10장) | 30 |
|  | 결과물 | 완성 기준 5개 ([15.5절](15-evaluation.md#section-15-5)) | 30 |

'각자' 활동 항목(커밋·PR·저장소 기여·이슈·충돌 해결)은 개인별 GitHub 기록으로 채점되므로 같은 팀이라도 점수가 다를 수 있습니다. 나머지는 팀 전원 동일합니다.

<a id="section-15-1"></a>

### 15.1 제안서 10점 + 발표 5점

| 항목 | 배점 | 만점 기준 |
| --- | --- | --- |
| 문제 정의·목표 | 2 | 어떤 문제를 푸는지 구체적 |
| 기능 설계 | 3 | 기능 4개가 1인 1기능으로 나뉘고, 각 기능의 완료 조건이 확인 가능(4.4 표) |
| 일정·역할 | 2 | 주차별 계획이 MVP(10주차)·동결(13주차)·릴리스(14주차)와 맞고, 역할 4개가 명확 |
| 협업 계획 | 2 | 브랜치·커밋·풀 리퀘스트·리뷰·이슈 규칙, 라이선스·행동 수칙 |
| 문서 완성도 | 1 | 7항목 형식 준수, 오탈자 없음, 저장소 주소 기재 |
| 발표 | 5 | 10분 안에 7항목(2), 전원 발언·전달(2), 질문에 근거 있는 답변(1) |

<a id="section-15-2"></a>

### 15.2 중간보고서 5점 + 중간발표 5점

| 항목 | 배점 | 만점 기준 |
| --- | --- | --- |
| 진행 요약·계획 조정 | 1 | 기능 4개의 상태가 풀 리퀘스트 번호로 확인되고, 남은 계획이 현실적 |
| MVP | 2 | 기능 2개가 실제 데이터로 동작(캡처와 시연 일치) |
| 협업 기록 | 1 | Insights 캡처·통계 표·브랜치 그래프, 충돌 사례 |
| 타 팀 기여·문제 대응 | 1 | 맡은 이슈 상태 기재, 문제 → 시도 → 해결 구조 |
| 발표 | 5 | 시연 성공(2), 구성·전달·전원 발언(2), 질의응답(1) |

### 15.3 최종보고서 10점 + 최종발표 5점

| 항목 | 배점 | 만점 기준 |
| --- | --- | --- |
| 기능·구조 설명 | 3 | 2~3장이 실제 저장소와 일치하고 그림·표로 설명 |
| 협업 기록 | 3 | 4장에 Insights 캡처와 수치 표, 충돌 사례 |
| 개인별·타 팀 기여 | 2 | 5~6장의 풀 리퀘스트·리뷰·타 팀 기여 링크가 확인 가능 |
| 문제 해결·회고 | 1 | 7~8장이 구체적(상황 → 시도 → 해결 → 배움) |
| 형식 | 1 | 분량·파일명·목차·오탈자 |
| 발표 | 5 | 시연 성공(2), 구성·전달·전원 발언(2), 질의응답(1) |

<a id="section-15-4"></a>

### 15.4 활동 규칙 30점

10장의 규칙 표 10개 항목 × 3점. 항목당 충족 3점 / 부분 충족(70% 이상) 1.5점 / 미충족 0점.

<a id="section-15-5"></a>

### 15.5 결과물 30점 (완성 기준 5개)

| 항목 | 배점 | 만점 기준 | 부분 점수 예 |
| --- | --- | --- | --- |
| 기능 동작(기준 2) | 12 | 기능 4개 모두 동작, 시연 성공 | 3개 9점, 2개 6점, 1개 3점 |
| 실행 재현(기준 1) | 6 | 새 폴더에서 README대로 실행 성공, v1.0.0 태그 | README 보완 후 성공 4점, 태그 없음 -2 |
| 문서(기준 3) | 6 | README 7항목, CONTRIBUTING·행동 수칙·<br>LICENSE | 항목 누락 1개당 -1 |
| 협업 절차(기준 4·5) | 6 | 모든 기능이 풀 리퀘스트·리뷰로 병합, 타 팀 이슈 해<br>결·병합, 받은 풀 리퀘스트 병합 | main 직접 커밋 있음 -2, 타 팀 기여 미병<br>합 -2, 받은 풀 리퀘스트 미처리 -2 |

<a id="section-15-6"></a>

### 15.6 감점·무효

| 행위 | 처리 |
| --- | --- |
| 다른 저장소 코드를 출처 표기 없이 복사(라이선스 위반 포함) | 해당 기능 결과물 점수 0 |
| AI로 만든 코드를 설명하지 못함 | 해당 풀 리퀘스트 활동 집계 제외 |
| main 강제 푸시, 보호 규칙 해제, 리뷰 없는 병합 | 활동 규칙 7번 0점 |
| 허위 회의록·활동 로그 | 회의록 항목 0점 |
| 제출 마감(목 18:00) 초과 | 지각 제출은 각 제출물 총점에서 10% 감점 |
