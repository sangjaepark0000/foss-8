## 3. 논의 내용과 결정 사항 (이유 포함)
- 회의 시간 변경: 금요일 09시에서 수요일 18시로 변경. 강의 내용을 반영하고 개발 진행 상황을 공유하기에 적합하다고 판단함.
- 깃허브 조회 방식 논의: gh 사용을 채택함. 로컬 Git은 확인 범위가 제한적이고, API 직접 호출은 사용자 설정 부담이 있어 기존 gh 명령어를 활용하기로 함.
- 서식 기능: 회의록 사용자 편의 개선을 위해, 단순 서식만 불러오는 것이 아니라 주차별 할 일, 팀명·팀원(사용자 1회 입력)을 채워주는 기능을 구현하기로 함.
- 프로토타입: CODEX로 핵심 기능만 간단하게 구현한 프로그램을 만들어 사용해보기로 함. 직접 사용자 경험을 체험하고 개선하기 위함.
- 다른 팀에게 맡길 기능 후보: 잘못된 형식의 데이터 입력 시 예외 처리, 나머지 후보 하나는 개발을 진행하며 논의하기로 함.
